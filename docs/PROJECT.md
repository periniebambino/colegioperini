Redesign completo, responsivo, orientado por branding, confiança, clareza e conversão.

## Princípios
- Fotografia como protagonista.
- Branding Perini preservado.
- Azul institucional como base; laranja para energia/ação; verde como apoio.
- Mobile tratado como produto, não adaptação.
- Conteúdo editável sem necessidade de alterar o layout.
- Sem números, depoimentos ou benefícios inventados.
- Performance baseada em HTML, CSS e JavaScript enxutos.
- Deploy sem etapa de compilação.
